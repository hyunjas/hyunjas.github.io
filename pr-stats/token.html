Get a GitHub token

A token isn't required, but it raises GitHub's search limit from about 10 to 30 requests per minute, so stats for active users load faster. The token only needs read access to public data.

Option 1: Let ChatGPT do it for you

Use a ChatGPT mode that can operate a browser, such as agent mode or the ChatGPT Atlas browser. Paste this prompt: 

Use my browser to navigate to GitHub Settings and help me create a fine-grained Personal Access Token for accessing public pull request data through the GitHub API.

Use the minimum necessary read-only permissions. Set an expiration date of 30 days.

If GitHub requires authentication, confirmation, or displays the generated token, let me handle that step securely. Do not paste the token into our conversation.
  1. ChatGPT opens GitHub and fills in the token form.
  2. When GitHub asks you to sign in or confirm, take over and do it yourself.
  3. When the token appears, copy it yourself. GitHub shows it only once.
  4. Paste it into the Personal access token field on the PR stats page.

Option 2: Create it yourself

  1. Open GitHub → New fine-grained token (Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  2. Token name: anything, for example pr-stats.
  3. Expiration: 30 days.
  4. Repository access: choose Public repositories. This gives read-only access to public data.
  5. Permissions: leave them all unset. None are needed.
  6. Click Generate token, copy it, and paste it into the PR stats page.

Keeping your token safe

Your token is stored only in your own browser and sent only to GitHub's API. It is never sent to this site. Don't paste it into chats, emails, or code. To remove it, clear the token field and click Analyze, or delete the token on GitHub under Settings → Developer settings → Personal access tokens.
